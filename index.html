Turning curiosity into

I'm a 5th-semester B.Tech Computer Science student with a deep love for the command line and system-level problem solving. I spend most of my time building Python CLI tools, developing desktop applications with PyQt6, and automating everything I can get my hands on.

My journey started with tinkering — breaking and rebuilding Linux installations until I understood every dotfile and system service. That curiosity evolved into crafting utilities that save real time, from cross-platform file managers to device sync tools.
